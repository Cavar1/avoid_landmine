# 扫雷

一个跑在浏览器里的经典扫雷游戏，**像素风 + Windows 95 复古外观**。纯前端单页应用，没有后端、没有排行榜，打开就能玩。

**在线试玩：<https://mines.cavar.dev>**

## 玩法与特色

- **三档难度**，对齐经典 Windows 扫雷：初级 9×9 / 10 雷，中级 16×16 / 40 雷，高级 16×30 / 99 雷。
- **首击必安全**：第一次翻开时才布雷，并排除首击格及其 8 邻域，不会开局踩雷。
- 左键翻开；右键在 未翻开 → 插旗 → 问号 → 未翻开 之间循环。
- 剩余雷数与计时用 **7 段数码管**呈现，计时上限 999 秒。
- **三套主题**：经典 / 暗夜 / 糖果，即时切换并记住选择。
- **实时合成音效**（翻开、插旗、踩雷、胜利），可一键静音，不加载任何音频文件。
- **战绩记录**：各难度的开局次数、胜局、负局与最快用时，存在浏览器本地，刷新不丢。
- **右键笑脸**弹出「选项」弹窗：游戏记录 / 新游戏 / 设定与偏好 / 关于扫雷。
- 所有图标均为手写内联 SVG，无图标库依赖；棋盘在窄屏可横向滚动，不破版。

## 技术栈

Vue 3 + TypeScript + Vite，包管理用 pnpm，**运行时依赖只有 vue**。

- 原生 CSS + CSS 变量实现主题，无预处理器、无 UI 组件库（避免样式冲突破坏像素观感）。
- 棋盘逻辑写成不依赖框架的纯函数（`src/utils/board.ts`），由 Vitest 覆盖。
- 音效使用 Web Audio API 实时合成，图标为纯 `path` 绘制的 SVG 组件。
- 数据持久化走 localStorage，不可用时静默退化为内存，不影响游戏。

## 本地运行

```bash
pnpm install
pnpm dev        # 开发服务器 http://localhost:5173
pnpm build      # 类型检查 + 构建到 dist/
pnpm preview    # 预览构建产物
pnpm test       # 运行单元测试
pnpm typecheck  # 仅类型检查
pnpm format     # Prettier 格式化
```

构建产物是纯静态文件，把 `dist/` 丢到任意静态托管即可上线。

## 目录结构

```
src/
├─ App.vue            # 页面装配：头部 + 棋盘 + 弹窗挂载点
├─ types/             # 游戏相关类型定义
├─ utils/             # 棋盘纯函数、常量、存储封装
├─ composables/       # 游戏状态机、计时、音效、记录、设置、弹窗管理
├─ components/        # 按职责分层：board / header / dialog / options / icons
│  ├─ board/          # 棋盘与格子
│  ├─ header/         # 顶部信息栏与数码管
│  ├─ dialog/         # 通用弹窗外壳与挂载点
│  ├─ options/        # 「选项」弹窗内容与弹窗内控件
│  └─ icons/          # 手写 SVG 图标组件
└─ styles/            # CSS 变量、三套主题、公共基元
```

面向开发者的架构约定、代码规范与验证方式见 [AGENT.md](./AGENT.md)。

## 关于这个项目

**绝大部分代码由 AI 生成**，作者负责提需求、做设计取舍与验收。项目从零开始搭建，游戏逻辑、像素视觉、音效与交互均由 AI 参与实现。
